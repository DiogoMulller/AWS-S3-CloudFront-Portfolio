2. Sugestões de imagens: distribuição CloudFront com origem S3 e default root object; bucket com bloqueio público ativo; permissões OAC sem dados de conta; site aberto em HTTPS; alertas AWS Budgets com e-mail oculto.
3. Salve capturas revisadas nesta pasta e adicione links no README principal.
4. Não poste chaves de acesso, tokens, credenciais ou informações financeiras privadas.
